# Sobre mí (edítame)

Este archivo es un ejemplo. Reemplázalo con información real sobre ti:
tus proyectos, tu rutina, tus gustos, cosas que quieras que Miku recuerde
sin tener que repetirlas en cada conversación.

Puedes agregar tantos archivos `.md` como quieras dentro de esta carpeta
(`data/memories/`). Cada vez que agregues o edites uno, vuelve a llamar al
endpoint `POST /rag/reindex` para que Miku "aprenda" el contenido nuevo.
